# Synthea 药物映射复核（2026-11-07）

结论：旧版损失主要发生在药物映射，不是空操作筛选。新版保留原 A1 v3 划分和 ATC 第三级标签定义，恢复全部1433条训练样本，训练类别由24变为38。新版数据及20轮完整训练均已完成，见[新版运行报告](sspnet-synthea-product-v4.md)；旧版20轮指标只属于旧版24类数据。

## 为什么旧版只有24类、822条训练样本

A1 主队列2948次就诊含77种不同RxNorm药物编码，训练就诊包含其中72种。旧映射表中，39种编码可唯一映射，24种一对多、14种无匹配。一对多和无匹配全部排除，剩余编码又合并为较粗的ATC第三级类别；训练词表最终只有24类。

按“每次就诊内去重后的药物编码出现次数”统计，共4095次，旧版仅保留2461次（60.10%），排除一对多1240次、缺失394次。这不是原始medications.csv的处方行覆盖率，也不是全数据131种药品的覆盖率。

训练候选1433条中，421条映射后目标为空，另190条没有可用映射用药历史，最终822条。这两个排除数按实际筛选顺序互斥。

## 新版怎么恢复

1. 优先使用NLM产品级[ATCPROD](https://lhncbc-portal.lhcaws-prod-pub.nlm.nih.gov/RxNav/applications/RxClass-ATC-product-classes-ATCPROD.html)。它考虑剂型、强度和复方，避免把同一成分的所有用途都混入标签。使用查询返回的**相同RxCUI成员**，不把相关品牌、复方药包的类别直接赋给原药。
2. 无精确产品级匹配时，使用ATC成分映射；只有归并至第三级后唯一才直接采用。两者都缺失才回退旧表。实际本队列73种由精确ATCPROD解决，1种由唯一ATC解决，未触发旧表回退。
3. 剩余3种由项目根据NLM成分/剂型记录和WHO ATC索引建立显式交叉表；这是本项目的术语推断，不冒充NLM官方分配，也不属于临床审核。它们恰好都在公开ATC候选集合内，无任意新增类别：

| RxCUI | 药物与剂型 | ATC第五级依据 → 模型第三级 |
|---|---|---|
| 895994 | 氟替卡松定量吸入剂 | [R03BA05](https://atcddd.fhi.no/atc_ddd_index/?code=R03BA05) → R03B |
| 896209 | 氟替卡松/沙美特罗干粉吸入剂 | [R03AK06](https://atcddd.fhi.no/atc_ddd_index/?code=R03AK06) → R03A |
| 105078 | 青霉素G注射液 | [J01CE01](https://atcddd.fhi.no/atc_ddd_index/?code=J01CE01) → J01C |

只向RxNav查询标准药物编号，不发送患者或病例。公开响应快照在 ../resources/rxclass-synthea.json，ATCPROD版本1.2026.7，ATC版本2026_01_28；项目补充交叉表在 ../resources/dose-form-crosswalk.json，附成分、剂型、来源链接和核对范围。训练时只读固定快照，不联网查询。

## DDI没有随映射一起“自动补齐”

38类中34类能连接现有drug-atc.csv中的CID节点，A10A、B03X、C07C、C09D缺少该连接。它们保留在推荐目标中，不能当作已通过DDI核查。新版graphs.npz另存ddi_mapping_mask，仅两端都能连接CID的药物对参与DDI率分母和动态损失切换，并报告总预测药物对、未映射对和映射比例；没有可计算的药物对时DDI率为null。损失只约束已知DDI边。

该mask只表示编码连通性，不表示全面医学证据覆盖。图仍沿用上游频次最低40个事件组筛选，未连边不等于无相互作用。新版DDI率与旧版全部药物对分母的DDI率不能直接比较；公平对照须采用同一药物集合和计算范围。
