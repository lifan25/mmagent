# DDI 溯源与第一批探索性对照

日期：2026-11-14。固定数据为 `synthea-v3-atc3-product-v4`，原运行为 `sspnet-synthea-v3-product-cpu-seed8`。本批不更新模型参数，测试结果复用已存分数；只额外读取最佳权重计算验证分数，复算与原验证 Jaccard 一致。既有测试集已用于错误分析，本报告属于探索性诊断。

## 1. 当前 DDI 代表什么

链路是：RxNorm 产品 → ATC 第三级类别 → `drug-atc.csv` 中的成分 CID → `drug-DDI.csv` 中的副作用关联 → 类别图。原文件来自 MoleRec 的公开材料，参考提交 `dd5afaf0a503fd3de3229f86ec7f26b345d10e3a`，不是已核对一致的 SSPNet 作者实验数据。

逐行重建结果：

| 对象 | 实际数量 |
|---|---:|
| 源文件记录 | 4,649,441 |
| 事件编号/名称组 | 1,317 |
| 全事件去重后的无序 CID 对 | 63,473 |
| 最低频 40 个事件组筛选后记录 | 476 |
| 筛选后不同 CID 对/事件三元组 | 476 |
| 38 类词表上的选定图无向边 | 75 |
| 全事件投影图无向边 | 521 |

重建选定图与训练使用的矩阵逐元素完全一致。上游 `processing.py` 降序排列后取 `tail(40)`，字面含义是最低频事件；当前实现对并列频次另用字典序固定，不声称并列处理与作者完全相同。事件频率不是严重程度。

[Decagon 原论文 §2.2](https://cs.stanford.edu/~marinka/papers/decagon-ismb18.pdf) 将 TWOSIDES 描述为来自不良事件报告系统的组合用药副作用关联，报告 1,318 种事件、4,651,131 条关联。现有下载件比该描述少 1,690 行和一个事件组；虽去重药对数量相同，仍不能声称文件完全一致。关联、临床禁忌、实际发生不良事件是不同对象。

### 最高贡献边的具体证据

预测中 `M01A–N02B` 被标记 87 次，占全部 140 次图标记的 62.14%。选定源数据支持这条类别边的只有一条记录：

- `CID000002244` 与 `CID000005090`，事件 `C0025218 / chloasma`。
- 前者源映射包含 `A01AD05 / B01AC06 / N02BA01`，后者为 `M01AH02`。
- 程序把这对具体成分的关联投影为 `M01A–N02B` 类别边，从而标记落入这两个类别的所有预测组合。

这证明了类别聚合的范围扩大，**尚不证明这 87 次全是假阳性**：模型只输出 ATC 第三级，具体成分并未确定。不能偷用当前真实处方的成分替预测结果补齐信息。完整边溯源在同名聚合 JSON 中，无病例标识。

## 2. 分母与训练行为

原 38 类预测共有 373 个药物对，其中 296 对两端类别均能连接到某个 CID，77 对不能；选定图标记 140 对。

- 全部预测对口径：140/373 = **37.53%**。
- CID 可映射对口径：140/296 = **47.30%**。
- CID 映射比例：296/373 = **79.36%**，不是已完成临床核查的比例。
- 同一预测改用全事件投影图：296/296 = **100%**（全对口径 296/373）。仅作图定义敏感性诊断，不据此替换训练图或认定全部预测有害。

不得用图中无边表示无风险，也不能换一个更低的分母口径后宣布模型改进。只有一个预测药物时没有可评价药对，DDI 比率为 `null`，不能把“不存在药对”报告成“证明安全”。

完整读码确认 SSPNet 原实现确有概率外积：`L_ddi = 0.0005 * p^T A p`，能传回梯度，不存在缺失外积的问题。对称图会计两次无向边，因此也等于 `0.001 * sum(i<j, Aij*pi*pj)`；它不是归一化 DDI 比率。

本项目 38 类训练将 CID 可映射分母同时用于动态损失权重：`beta=min(exp(2.5*(1-rate/0.06)), 1)`。例如 rate=0.5 时 beta 约 1.09e-8，监督项权重很小。24 类旧版使用全部预测对；因此新旧训练差异不只有词表和样本数，不能直接归因于映射改进。无可映射对时训练 rate 暂取 0 是代码回退，不是安全判断。后续若比较两种分母，必须固定队列、词表、图、种子与其他设置，只改变这一处。

### 实际损失探针

固定最佳检查点、种子20261114，从1433条训练记录无放回取32条，CPU单线程、eval模式，无优化器。原始损失与双精度二次型最大绝对误差1.17e-10；原始logits梯度与公式梯度最大差3.49e-11；1216个坐标的中央有限差分最大差1.51e-14。模型状态未变，参数.grad未填充。这里的logits指模型输出的未归一化分数，所测不是参数梯度。

该小样本共有26个预测对，其中20个可连接CID、6个未知对，6个被图标记：全对率23.08%，映射对率30.00%。两种分母的beta分布在这批样本中相同：26条为1，6条小于0.01，其中5条小于1e-6。因此**未观察到该固定小样本上beta改变，也不能证明分母修改造成了历史训练问题**。

监督项/DDI项未加权logits梯度L2范数的逐样本均值为0.00801485/0.0000362398，加权后为0.00302739/0.0000323090。均值不能代替逐例机制分析，更不能推断完整训练轨迹。完整聚合、分位数及运行信息见[探针JSON](ddi-loss-probe-20261114.json)。

## 3. E1：简单基线

最近一次历史基线仅使用当前就诊之前最近的非空药物集合。频次基线只用训练标签统计类别，预测数量为训练目标平均数量四舍五入，得到 k=1、类别 N02B；未按验证/测试挑 k。SSPNet 阈值保持 0.5。

| 方法 | 验证 Jaccard | 探索性测试 Jaccard | 测试 F1 | 平均预测类别数 | 标记对/可映射对 | 未映射对 |
|---|---:|---:|---:|---:|---:|---:|
| 最近一次非空历史 | 34.50% | 35.25% | 37.24% | 1.339 | 42/138 | 43 |
| 训练频次固定 k | 25.49% | 24.69% | 25.07% | 1.000 | 0/0（不可算） | 0 |
| 现有 SSPNet | 74.43% | 74.65% | 80.91% | 1.655 | 140/296 | 77 |

SSPNet 超过这两个廉价对照；尚未与同条件现代模型及无历史诊断模型比较，不能据此证明历史模块或拟议新方法有效。硬集合基线 AP 是 0/1 两级并列排序，与模型连续分数的排序信息不同，主表不拿 AP 作核心比较。

|---|---:|---:|
| 当前无操作记录 | 202 / 75.12% | 212 / 75.42% |
| 当前有操作记录 | 152 / 73.52% | 139 / 73.48% |

保留空操作与一次历史样本，没有观察到应删除它们的证据。一次历史加当前目标就是至少两次就诊；这里没有评价完全无历史患者。同一患者可以进入不同分组，不能把分组当作独立样本作普通显著性检验，也不能从此推断空操作更有利。
