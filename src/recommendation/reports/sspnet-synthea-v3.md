# SSPNet Synthea v3：实际端到端运行结果

日期：2026-11-07。已完成依赖安装、正常原包导入、实际数据准备、20轮全训练、验证选模、最佳权重加载到新模型、重载一致性核对、固定测试集一次评价。原始 SSPNet 子模块未修改；运行与差异详见 [RUNNING.md](../RUNNING.md)，机器可读聚合证据见 [results JSON](sspnet-synthea-v3-results.json)。

## 环境与运行

Windows / Python3.10.22 / torch2.7.1+cu128；PyG2.7.0、torch-scatter2.1.2+pt27cu128、OGB1.3.6、RDKit2025.9.1、scikit-learn1.7.2等依赖已实际安装。uv pip check 检查58个包兼容；原模型和 training 包正常导入，不使用 AST 隔离。

GPU逐样本吞吐约每轮100秒，CPU单线程约每轮48秒，按吞吐选择CPU完成独立20轮主运行。GPU速度试跑未作为最终权重或测试结果。原模型主要结构与损失保留；接口、绘图、两项未初始化参数及原验证入口错误的适配见运行说明。

## 数据范围与排除

A1 Synthea v3 的有历史样本为2139条（1433/355/351）。本次将RXCUI精确映射到无歧义的四字符ATC第三级类别，排除未匹配、多类别歧义，以及映射后没有目标或已知药物历史的样本。没有删除A1全量病例。

A1候选就诊中的4095次药物编码出现，2461次精确且无歧义匹配（约60.10%）、1240次多类别歧义、394次无匹配。此计数按就诊内药物编码出现，不等于原始处方CSV行数。训练词表为96个诊断、62个操作（各含内部UNK）、24个药物类别；并非论文的131种药物。

空目标/无已知药物历史排除分别为训练421/190、验证112/45、测试96/39。验证与测试只评价可映射且在训练词表内的目标子集，不能把分数解释为全部原始RxNorm处方的准确率。未知诊断/操作使用明确内部UNK并计数；空操作保持真正空集合。

EHR图只用训练就诊，含59条无向边。DDI按照上游字面最低频40个事件组过滤、词典序处理并列，再投影到同一药物词表，476条源记录得到34条无向边。不是最高频或经验证最严重的40种；DDI值只表示该子图上的冲突率，不证明临床安全。

## 训练和测试结果

seed8，隐藏维度64，Adam，学习率1e-4，阈值0.5，target_ddi0.06、coef2.5。20轮完成，按验证集逐就诊Jaccard选择第19轮（验证86.2795%）。模型563907个参数，总耗时958.55秒，约15.98分钟。未在测试集调参或选权重。

## 空操作与保存重载的证据

- 共16440个优化步骤，当前空操作9500步、含空操作历史14480步；每步检查输出、损失和梯度有限性，全部通过。
- 已验证当前空操作样本确实更新参数，不只是调用前向。
- 验证集每轮包含123个当前空操作样本；最终测试含137个，其中125个同时有空操作历史，全部完成评估，没有因操作为空跳过。
- 保存最佳权重后加载到新模型，用验证样例核对重载输出完全一致；测试集仅在此之后评价一次。
- 5个推荐模块测试及11个A1测试通过。用保存的测试分数独立重算Jaccard、F1、AP和DDI对数，与结果一致，没有再次运行测试模型。
