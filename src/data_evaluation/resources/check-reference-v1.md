# 来源独立编写核查参照 v1

[JSON](check-reference-v1.json) 包含40条明确虚构的候选与事实组合，覆盖5个规则族。它用于核对来源解释、适用范围与未知处理，**不是临床专家金标准、实际患者队列或真实核查准确率验证**。

编写者是单独角色的agent：读过旧版检查器和旧单测，在本轮来源与范围确定后独立重读官方原文；编写期待值前未读取新增production规则JSON、实现或病例预测/核查输出，未调用 `check` 或 `evaluate_condition` 生成期待。与实现角色共享基础模型和部分权威来源，因此不宣称统计独立或消除共同解释错误。每条 `expected` 和理由都是显式静态文字；首次执行前冻结。若实现不符，应先保留失败，核对来源后再区分实现错误或参照错误，不能根据输出改期待凑满分。

| 期待状态 | 本参照含义 |
|---|---|
| flag | 这条来源规则支持标记；CAD是避用警告，药对是潜在并用复核，不统一说成绝对禁忌 |
| clear_within_rule | 已知事实不触发该单条条件，未评价其他禁忌或整份处方安全 |
| unknown | 所需事实/产品身份未知或输入无效，不能当阴性 |
| not_applicable | 身份及范围明确不匹配，或候选中没有定义的药对；不等于无风险 |

评价单位是一个虚构候选集合与一个规则族，使用行内 `rule_ids` 选择该族。评分器只能读取静态标签比较结果，不读取condition树构造真值。产品身份缺失时，生产返回的外层 `not_checked` 可能仍对应这里的 `unknown`，应结合缺失原因区分；布洛芬100mg属于已解析身份但超出本轮直接来源范围的 `not_applicable`。这些状态是协议约定而非新的临床断言。

参照包含：二甲双胍低于/等于/高于阈值；已知阳性、明确阴性、缺失与非法类型；远期手术史不能替代同次手术、脉搏/高血压不能替代CAD；已识别范围外与未解析药物；阿片复方、苯二氮䓬组合和只存在既往记录的反例。`false` 仅为人工明确给定的假设事实，不能据此给Synthea缺失记录填阴性。药物对提示仅基于本次候选，不证明实际同时给药。

来源URL、章节、访问日期和准确转述都在JSON内；没有把规则程序自己的输出当标签。年龄、体重和一般化验没有因容易获得而被包装成无条件安全通过规则。FDA/DailyMed产品标签只支持相应药品与临床条件，参照未覆盖其他疾病、制剂或所有相互作用。

建议公开四态混淆矩阵、每规则族/每期待状态的一致率，以及未知被误判为通过、应标记被漏报、非标记误报警的数量。0分母记为null。不要把人工安排的状态比例当临床患病率或核查覆盖率；实际固定351条输入的覆盖与此参照分开报告。该参照是独立于新增实现的来源一致性检查，仍需后续独立临床审核和未参与开发的真实队列确认。
