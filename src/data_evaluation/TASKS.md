## 第一阶段任务与交付顺序

### A1：病例组织与划分，优先交付给 B

输入：Demo/Synthea 原始 CSV 和来源版本。先用 Demo 核对关联，再以 Synthea 作为首轮推荐模拟开发数据；两者独立输出。

计划提交：prepare.py、configs/ 下的筛选/划分配置、tests/ 下的病例组织检查、reports/data-summary.md，以及实际运行 README。

- [x] 为 MIMIC Demo、Synthea 分别读取并关联就诊、诊断、操作、药物。使用各自的编码体系，不拼接不同数据集患者。
- [x] 按真实时间排序同一患者的就诊，去重当前集合，记录缺少诊断/操作/药物的就诊及筛选原因。Synthea 慢性病是否跨就诊延续需明确，不凭空补全。
- [x] 统一导出原始编码病例：patient_id、visit_id、时间顺序、diagnoses、procedures、medications；药物是监督答案。B 在此基础上建立整数词表；预测适配必须把当前药物剥离。
- [x] 固定 seed 和患者级 4:1:1 划分；同一患者的所有就诊只在一个集合。小样本不足时明确报告，不承诺任何预定有效样本数。
- [x] 本地保存病例、划分清单和来源版本；Git 只提交代码及汇总人数、就诊数、缺失/排除数量，不提交真实 ID 和逐病例记录。
- [x] 检查同日多次就诊、重复编码、空操作、无处方、药物记录找不到对应就诊等情况；不直接用内连接悄悄丢掉所有不完整病例。
- [x] 统计逐步筛选前后患者/就诊数、至少 2/3 次有效就诊的患者数。有效数不足时交付真实统计，由 A/B 决定是否调整筛选；不复制病例补足集合。

交给 B：visits、split 和 manifest 的本地产物位置，具体含义见 [协议第 9 节](../../docs/protocol.md#9-开发交接文件约定草案)。交给 C：共享 Case 字段草案、未知值规则与明确虚构的联调样例。不要等 A2/A3 完成才交接 A1。

A1 验收：成员按 README 从同版源表重新组织得到相同聚合统计；患者集合交集为空；历史严格早于当前；推理 Case 没有当前药物字段。首个 PR 建议 a/cases-and-split，只交 A1，不夹带模型或核查代码。

### A2：统一评价和验收

输入：先用可手算的虚构标签/分数检查，B3 后接收其全词表分数与模型词表标识。计划提交：evaluate.py、tests/ 指标检查、reports/evaluation-definition.md。

- [ ] 提供 Jaccard、F1、PRAUC、DDI rate、平均推荐药数的统一计算；与 B 确认全词表分数、阈值与空预测处理，不只拿展示候选计算 PRAUC。
- [ ] 用可手算的小样例检查指标、患者不重叠、时间顺序、输入不含当前药物和未来记录。
- [ ] 审核 B/C 的 PR，核对运行证据、目录范围和接口；公共协议由 A 汇总修改，实际对齐后再冻结 0.1。
- [ ] 明确每个指标的样本单位、平均方式和零分母处理。PRAUC 使用全词表分数；DDI rate 明确是全局药物对比例还是逐就诊平均，不混用两种口径。
- [ ] 明确未支持输入、未映射药物与空预测如何计数，报告实际评价样本数及排除原因；不只统计“成功预测”的病例而隐去失败率。

A2 验收：至少一个完美预测、一个部分命中、一个空预测样例可人工核对；和 B 输出对齐同一 case_id/词表；阈值只从训练/验证确定。可以在 B 模型未就绪前先提交手算检查和定义。

### A3：两模块通过后再集成

前置：B 的 recommend 和 C 的 check 接口已可独立调用。计划提交：pipeline.py、tests/ 联调检查、reports/integration.md 和从数据到输出的运行步骤。

- [ ] pipeline.py 顺序调用 B 的 recommend(case) 与 C 的 check(case, recommendation, rules)，输出候选、核查状态、来源和未覆盖项。

- [ ] 提交总运行说明：如何准备数据、运行各模块、定位本地产物和复查汇总结果。展示阶段不要求网页或复杂 agent 框架。
- [ ] 检查缺字段、B 返回非 ok、模型/词表不一致、C 缺事实和未加载规则时的行为；B 失败时不能继续伪造候选给 C。
- [ ] 对同一病例保留原候选及核查结果，解释只引用真实返回的规则和来源，不另外编写一段无来源的诊断建议。

A3 验收：A 能通过一个入口复现推荐→核查→报告；逐病例输出留本地，PR 提交聚合报告和明确虚构的演示。C2 原诊断分支尚未完成时，集成可以单独交付，但不得据此宣布两篇论文均已复现。
