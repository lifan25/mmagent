# 公开数据与独立患者条件核查：准备结果

日期：2026-11-14。基线提交：`2d0e3b43a1ee18ee6b710c4b343577b1375af050`。本批完成数据适用性审计、固定20题输入包、两份空标注包及输入可执行性草稿；**尚未完成双人人审或新增核查准确率实验**。无新模型、训练、规则增补或195条DDI确认集开封。

## 现有数据能支持什么

| 材料 | 可用标签与用途 | 本轮决定 |
|---|---|---|
| Synthea、MIMIC Demo | 病例事实与既有处方；没有独立药物风险裁定 | 保留推荐/集成开发；处方不能当安全标签 |
| DDICorpus-2013 | 文本中是否表达DDI关系 | 可独立评价文本抽取，不等于患者禁忌 |
| 250份DDI药单 | 外部作者指定的阳性交互药对 | 可评价指定药对定位；195份确认集继续封存 |
| DialMed | 对话对应的推荐药物 | 不作为风险核查标签 |
| 自编40条参照 | 来源解释及虚构事实组合 | 回归检查，不是独立临床金标准 |

DDI清单的[原论文方法](https://pmc.ncbi.nlm.nih.gov/articles/PMC13505366/)说明由三位临床药师依据LexiDrug构建，每单一个目标交互药对；它没有患者肾功能、疾病等条件，也没有阴性清单。其外部参考答案价值保留，但不能代替本轮患者条件任务。

补充材料只选一套：[作者MedPIC-Bench](https://huggingface.co/datasets/TIM0927/MedPIC-Bench)，CC BY 4.0。固定提交`9ef6db4f13865b14fc2e6be3f94dcfaf3a0cf983`，`questions.json`为489,402字节，原文件SHA-256为`c28c054ed788de7cbaf7592883e90ef85e530cf9464019dfd39618dcc5ea4ae6`。原始题、README许可声明、source.json均在本地`data/local/medpic-bench-20261114/`，不随Git上传。

[MedPIC方法](https://arxiv.org/html/2608.03028v1#S3)报告所有题经过专家核验，共467题、284条固定病例题和183条反事实题。它们是模拟情景。外部作者答案可以用于独立作者标签一致性评价，但本组尚未复核逐题医学依据；公开文件没有逐题引用、来源规则ID、配对ID或RxNorm编码。不能由论文的来源清单猜每题出处，不能构造未经证实的反事实配对。

次选[RxSafeBench](https://github.com/CAS-SIAT-XinHai/RxSafeBench)本轮未下载全量。README的专家过滤描述与[论文§II-C/D](https://arxiv.org/html/2511.04328v1#S2.SS4)不同：正文报告GPT-4自动评分筛选，并把上游库没有目标禁忌/交互的候选视为安全。它不优于MedPIC满足本轮独立患者条件标签需求，不将其称为逐题专家金标准。

## 固定任务和抽样

主任务：给定病例明确提供的事实和备选药，逐候选判断是否触发题目要求的避免、禁忌或不适合提示。纯慎用/监测、剂量调整和最佳治疗单列；不把所有动作都转成禁用。候选选项不是共同处方，不能整体送入DDI核查。原作者未选的选项也不是“临床安全”标签。

准备前在A的TASKS登记：按原题干UTF-8 SHA-256、原始行号升序选前20题。固定选择不读答案、分类、模型表现；不因规则不支持换题。它是确定性的开发样本，不是随机代表样本。全部467题只有96种题干，441题共享重复题干；选中20题只有5种题干。余447题未用于本地调参，但缺少配对和来源规则分组，**不是已确认独立的测试集**。正式评价须先审查分组和重复，另行冻结用途。

## 实际执行结果

| 检查 | 结果及分母 |
|---|---|
| 数据格式 | 467条唯一原始ID、2,335个选项，每题5项 |
| 开发包 | 20题、100选项，输入仅病例文本/问题/选项；答案另存 |
| B/C空包 | 各20条pending，真实双人人审完成0条 |
| 输入题意初审 | AI草稿：17题in_scope、2题剂量范围外、1题语义待定；待人审确认 |
| 选项实体初审 | AI草稿：78个成分名、2个含外用途径的成分名、20个非药物选项 |
| 精确产品可解析 | 0/80个药物选项；没有擅补剂型、剂量、途径或产品RxCUI |
| 冻结规则可执行性 | 草稿审计0/20题具备完整执行条件；不是引擎运行成绩 |
| 新增模型调用/核查预测 | 均为0；原351条SSPNet结果与2/344核查覆盖未重跑、未改变 |
| 准备器相关测试 | 6项通过，覆盖答案隔离、题干重复、证据定位、未知值与保留已有标注 |

9题的候选含二甲双胍，但原文仅提供肾功能正常等定性描述，不能补成数值eGFR；候选也不提供冻结规则要求的精确产品。2题候选含华法林，而既有华法林妊娠规则已被拒绝，不能为覆盖率重新启用。当前完整执行为零说明**现有产品范围规则不能直接迁移到这套成分级选择题**，不等于MedPIC没有有效标签或这些药物没有风险。

原文CrCl与eGFR保持不同字段；成分名不能擅自变成已知复方或另一种同类药。输入审计不推断临床答案，只转写明确事实和列出缺口。全过程未使用作者答案选择样本、补事实、补药物或增补规则。

## 标注交付与独立性

规范见[C标注协议](../../knowledge/MEDPIC_ANNOTATION.md)，命令见[A运行说明](../RUNNING.md#medpic独立核查开发准备)。包内`author-reference.development.json`只给评价侧；B/C领取`inputs.development.json`与各自空模板，不领取答案、AI审计草稿或对方结果。

1. **A**维护原数据版本、固定输入和答案隔离，收回两份记录；对照完成数/共同完成分母汇总资格、事实和规则分歧。转写问题可裁决；医学分歧留未知并交老师或临床/药学人员处理。
2. **B、C分别独立**审20题：题型→全部选项身份→患者事实/单位/时间→原文证据→来源/适用范围。缺失保持null，范围外保留。标明真人或AI草稿，只有实际人审进入双人一致性统计。各模块TASKS已写领取、路径与验收。
3. **下一阶段的来源核查**只使用开发题：记录逐条来源、版本和与生产规则的重合；确认来源是否支持成分级规则及明确患者条件，再由C提最小适配。不得为了答对原题放宽产品限制或把“正常”换成数值。未明确分组的余题不能作为新增规则素材。

原始外部作者标签、我们的输入转写和未来临床裁定分别保存。来源相同、同一指南家族、不同一手来源、未知分别标记；不同仓库本身不能证明知识来源独立。

后续主指标预定为原题答案集合精确匹配、全资格题回答覆盖率及未知数量，未知保留主分母；只有全部必要候选可判断才能回答整题，不把未覆盖候选当阴性或默认“以上皆无”。完成题意/实体/来源转换与双审后再运行。没有公开配对ID时不报配对准确率，没有临床裁定时不报真实患者安全性。
