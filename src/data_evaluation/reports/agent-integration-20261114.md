# 两篇论文主线：最小可运行实现与集成

2026-11-14。本轮复用现有数据、SSPNet权重和Diaformer权重，补齐共享推荐接口、BIBM式知识形式化、受限MLN及agent调用链。零样本推荐实验未运行。当前成果是可复查的最小实现，原论文完整复现与真实临床验证仍未完成。

## 1. 实际调用链

`A1 Case → 输入检查 → SSPNet推荐 → 已审核自动规则核查 → 候选、来源、缺失项与下一动作`

B的`SSPNetRecommender.score_case`一次推理提供候选和全38类分数；A不复制模型实现。C的`check`保留未知、例外与未覆盖；A不修改候选，也不额外用语言模型生成无法追溯的解释。默认agent使用真实模型生成后经agent来源/逻辑核对的规则包，来源核对参照包另作对照。

共享协议仍为0.1-draft，已有实现但未冒称三名成员已正式确认。运行命令见[RUNNING.md](../RUNNING.md)，聚合结果见[同名JSON](agent-integration-20261114.json)。

## 2. SSPNet接口与固定病例

没有重训、改变阈值或重新划分。原351条Synthea测试输入全部保留；严格接口支持344条，7条因训练词表未支持的诊断/操作编码明确拒绝。拒绝对应5次未知诊断、6次未知操作出现；这是11次编码出现，不是11个病例。支持子集中211条当前操作为空。

| 项目 | 实际结果 |
|---|---:|
| 全部输入 / 可推理 | 351 / 344 |
| 推荐覆盖率 | 98.01% |
| 支持子集分数对原保存结果最大差 | 0 |
| 支持子集Jaccard / F1 | 74.69% / 80.94% |
| 全351条、未回答记零的Jaccard / F1 | 73.20% / 79.33% |

支持子集成绩不能当作原351条全队列成绩；小数变化来自分母，不是模型改进。AP只在有实际全词表分数的支持病例上计算，拒绝病例不填造分数。B还单独重放全部351条旧编码输入，逐位匹配旧分数；这不等于严格原始接口支持全部病例。

## 3. 自动知识提取与核查

三条官方药品标签先由agent核对、转述并确定谓词及药物范围，本地Qwen只形式化自然语言规则和条件树。保留生成、自评分、最多一次改写与独立来源核对。网页选择、摘要与编码不是本轮自动实现，具体范围见[C运行说明](../../knowledge/MEDICATION_CHECK.md)。

v1的3条输出均结构失败，完整保留。一次格式开发后的v2使用受控JSON结构，实际8次请求、约179.47秒：二甲双胍和布洛芬两条通过来源/逻辑核对；华法林条件树反转了例外含义，整条拒绝，不根据参照手工修成正确树。通过审核的自动规则仍保留模型原始statement/condition，审核主体是agent，没有人类或临床专家审核。

eGFR负值属于输入域无效，执行器固定检查其非负、有限、非布尔属性，不由模型决定。原首轮边界失败和同一原始输出的修正后审计均保留，不重新采样模型答案。有限虚构上下文检查只验证实现，不能称临床准确率。

| 同一344条推荐 | 来源核对参照（3条） | 默认自动包（2启用、1拒绝） |
|---|---:|---:|
| 信息不足 | 135 | 127 |
| 未覆盖 / 未检查 | 209 | 217 |
| 完整执行的成分规则判断 | 0 | 0 |

两次运行的351个推荐对象及全分数向量完全相同。自动包不能执行华法林错误规则，相关候选转为未覆盖；不能把“少检查/少报警”当效果提升。

**当前实质瓶颈是候选粒度。**SSPNet输出ATC3类别，没有确定的成分、途径、剂型；无法执行具体药物的禁忌规则。运行时没有借目标处方补身份，也没有将未发现冲突写成安全。规则触发、不触发、缺失、例外和拒绝分别在明确虚构边界样例中通过检查，未混进真实模型病例成绩。

## 4. BIBM诊断分支

诊断分支独立使用DXY，不与Synthea患者拼接。真实模型生成14条候选，来源核对拒绝2条外推，保留12条原始公式。复用冻结Diaformer重放339条训练问诊，约25.17秒、零权重更新；训练受限条件MLN并执行四组预设对照，共约0.21秒。

| 固定测试104条 | 正确数 | 准确率 |
|---|---:|---:|
| 仅疾病先验、无规则 | 24 | 23.08% |
| 显性症状＋规则 | 41 | 39.42% |
| 问诊后阳性症状＋规则 | 47 | 45.19% |
| 已有Diaformer | 79 | 75.96% |

受限MLN只包含观察阳性症状合取、单疾病硬约束与五个疾病世界，使用精确归一化和条件似然学习；公式推导及与原Alchemy/MCMC的区别见[BIBM_DIAGNOSIS.md](../../knowledge/BIBM_DIAGNOSIS.md)。尚未恢复完整知识检索与原文迭代优化。低于Diaformer的结果原样保留，未因测试表现补规则或换提示。
