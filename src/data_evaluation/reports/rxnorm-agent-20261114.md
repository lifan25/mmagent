# RxNorm产品级推荐与核查

设计基线：`c1c7adc`。以下设计在v5训练与测试结果生成前固定；本轮是现有合成队列上的探索性适配，不是新队列确认实验。

## 固定设计

1. 保持A1原患者划分、历史边界与输入字段，train/validation/test为1433/355/351；旧ATC3准备曾删除1条验证，本轮恢复并报告。保留空操作和至少一次已结束有效历史。
2. 输出原始RxNorm药物码，词表只从训练就诊建，共72种，66种出现于训练预测目标、6种仅作训练历史。完整原始编号不随意合并剂量、剂型或品牌。后续元数据核对明确：65个SCD通用制剂、4个SBD品牌制剂、2个BPCK包装、1个SCDC成分＋规格；897718未提供剂型，保持未知。72个标签不是72种成分，也不全是完整制剂；此语义核对没有改变标签或训练。训练词表中70个目前Active、2个Obsolete，旧编号不替换为猜测的新药。
3. 词表外真实目标计入集合指标的漏报，不删除病例。AP只在目标全可表示的病例计算，单列其分母；严格输入拒绝率与离线模型评价分开。
4. 20轮、seed8、dim64、lr0.0001、原损失设置、阈值0.5；只用验证Jaccard选权重。v5按严格输入策略将未支持病例计入全355条验证分母且集合指标计0，不对其推理、伪填概率；与旧版隐式UNK/丢历史药的离线策略不同。旧权重/图/运行目录保持原样；不按本轮测试结果换种子或阈值。
5. 新图以完整产品成分、NLM完整七字符ATC和原参考CID关系相连，明确无映射/多义；只从训练建EHR图。新旧图和输出维度均改变，因此不是“纯粒度消融”，也不能把图标记率变化当临床风险改善。
6. 对照原38类时，把新模型候选投影至旧ATC3空间，在同一病例比较集合指标。另用原类别预测加训练就诊内最常见产品作廉价精细对照；不读取当前真实药品挑候选。
7. 默认核查仍使用原模型提取的临床条件、拒绝的华法林规则保持禁用；产品身份由官方元数据提供。二甲双胍ER适用范围须有独立标签证据，不把它压成普通片。
8. 从同一原始ZIP读eGFR，限定同次就诊、结束时间前的最新有效值；同一最新时刻冲突则未知。单位为显式标准化单位，或严格LOINC33914-3且名称注明1.73的旧导出单位；规则依据[LOINC定义](https://loinc.org/33914-3/)。CABG只从同次已记录且未超过结束时点的手术置true，缺失不置false。事实均为回顾性核查输入，不用于SSPNet预测，不读取当前药品答案，也不推断既往测量仍然有效。
9. 固定同一细粒度候选，分别核查无新增上下文和真实记录上下文；候选与推荐指标必须相同。规则触发率、可执行率和建议正确率分开，后者尚无独立标签。

## 已完成的数据核对

已有ZIP中包含observations.csv，无需新下载。上下文版本`synthea-same-encounter-context-v1`：训练48/1433、验证13/355、测试14/351条有可用同次eGFR；阳性同次CABG分别10、1、3条。17次最新eGFR值冲突保持未知，20行时点不在就诊区间而排除；其余病例不补造测量或阴性。

## 实际推荐结果

唯一一次20轮CPU运行已完成，28,660次更新，用时2230.34秒（37.17分钟），按完整355条验证Jaccard选择第16轮。完整351条测试Jaccard为**65.30%**、F1为**71.05%**；7条输入拒绝计0，3条有词表外目标的病例仍保留，未见目标计漏报。AP为82.21%，仅针对341条输入支持且目标全部可表示的病例，不能写成351条AP。

下表固定同一344条输入支持病例。前两行比较原始RxNorm药品，后两行比较固定ATC3投影；不同空间的分数不直接比较。

| 输出与方法 | Jaccard | F1 | 平均预测数 |
|---|---:|---:|---:|
| 原始RxNorm：新72标签SSPNet | 66.63% | 72.49% | 1.724 |
| 原始RxNorm：旧38类SSPNet＋训练内类别众数产品 | 56.38% | 60.58% | 1.645 |
| ATC3：新RxNorm候选投影 | 75.47% | 81.71% | 1.622 |
| ATC3：旧38类SSPNet | 74.67% | 80.91% | 1.645 |

廉价产品对照只用训练就诊内各类别频次最高的原码，频次相同按字典序；没有由当前真实药物选择产品。ATC3比较双方均使用完整原始目标投影，其中1条支持病例包含训练词表外J01A。旧集成报告使用旧编码目标，未计该类别，因此旧报告的74.6941%/80.9423%与这里重算的74.6699%/80.9132%有小差异；没有改变旧权重或预测。

这说明在本合成队列的一次固定运行中，直接预测药品比简单的类别众数展开更准确；标签空间、图及验证输入策略同时改变，不能据此宣称某项机制独立有效或已获得稳定显著提升。

## 核查从不能执行到有限执行

两个核查分支使用同一份新权重、同一批351条原输入。所有候选及全词表分数完全相同；344条进入核查，7条输入拒绝。

| 核查结果（344条支持病例） | 无新增上下文 | 补原始同次记录 |
|---|---:|---:|
| 未覆盖 `not_checked` | 247 | 247 |
| 条件不足 `insufficient_information` | 97 | 95 |
| 已执行覆盖内规则 `checked` | 0 | 2 |
| 完成的规则判断次数 | 0 | 2 |
| 触发警告次数 | 0 | 0 |

两次都是已预测二甲双胍缓释产品的eGFR规则；取值有真实来源，未触发该规则的禁忌阈值。至少执行一条规则的覆盖为**2/344=0.58%**，按全部输入为2/351=0.57%。它不表示这两份处方的全部药品都已核查，更不能把其余未覆盖或缺字段病例判为安全。测试中虽有14条可用eGFR、3条阳性CABG，只有候选药品与规则条件同时匹配时才能执行。

另一个诚实对照：旧类别加训练众数产品，在相同真实上下文下可执行4次规则、触发1次警告（3条checked、1条issues_found）。因此本轮不支持“更细模型核查覆盖更高”或“更少警告代表更安全”。当前没有独立临床核查真值。

## 映射与DDI的边界

原77个药品中51个可完整连接到参考CID，训练72标签中46个完整、26个不完整。连接依据是官方基础成分、完整七字符ATC与固定参考映射中的唯一CID；唯一仅指该参考表内，无匹配或多义保留未知，不能说已独立验证全部化学身份。

固定40事件来源形成7条无向产品DDI边。预测产品对共387对，完整映射199对（51.42%），其余188对未知；其中1对命中图，图标记率1/199=0.50%。这与旧粗类别47.30%的节点及分母不同，不是临床风险下降的证据。本次预测中同单CID/成分CID重叠的产品对均为0；仍不意味着已检查重复用药。已知部分成分产生的1条边单列审计，不混入正式完整映射图或分母。
