# 患者事实、规则范围与独立编写参照

基线：b37ae20。保持原72标签SSPNet权重、阈值和351条测试输入；本轮不加模型、不重训。临床规则与事实策略先依据训练/验证源表和官方说明书确定，再检查既有固定预测，不根据测试命中追加规则。

## 已有数据能提供什么

审计只使用原2020年Synthea ZIP及本地CSV；训练1433条、验证355条的同次最新有效记录如下。没有把所有可读字段都塞进规则。

| 字段 | 原始依据 | 训练／验证可用数 | 本轮处理 |
|---|---|---:|---|
| 年龄 | 出生日期＋当前结束日期，整岁 | 1433／355 | 加入上下文；无年龄规则，不计为核查完成 |
| 血压、心率、体重 | LOINC 8480-6/8462-4、8867-4、29463-7，原单位 | 各188／47 | 仅审计；不由正常值推断无心脏疾病 |
| 血钾 | 6298-4，mmol/L | 97／19 | 仅审计；没有因数值容易取得而临时编阈值 |
| 肌酐 | 38483-4，mg/dL | 76／15 | 另21／4最新同刻冲突保持未知，不计算替代肾功能 |
| eGFR | 原33914-3规范及旧单位核对 | 48／13 | 原v1值完整保留；不把它当肌酐清除率CrCl |
| ALT／AST | 1742-6／1920-8，U/L | 各22／6 | 未提供化验上限，不能据正常值排除活动性肝病 |

| 已记录冠心病 | SNOMED-CT 53741008＋来源就诊边界 | 124／32 | 只产生有据阳性或unknown，从未由缺记录生成false |

现有过敏表只有食物、环境、动物和乳胶，不能补药物过敏或“无药物过敏”。妊娠来源有开放STOP及异常长区间，例如26条输卵管妊娠中23条未记结束，另3条持续1330、168、6797天；本轮不把这类开放记录跨次当当前妊娠，也不由性别判断妊娠阴性。

冠心病的START是诊断日，ENCOUNTER是诊断来源就诊，STOP是缓解日（如适用），依据[Synthea官方字段定义](https://github.com/synthetichealth/synthea/wiki/CSV-File-Data-Dictionary)。本轮要求来源患者一致、来源就诊时间有效，且为同次已结束就诊或当前开始前已结束的历史就诊；诊断日不晚于截止日，未记录截至截止的缓解。STOP在截止当日因缺时刻保持未知。没有独立录入时间，不能把START伪装成recorded_at；早1日的原始诊断日期保留审计，未修补或猜测时区原因。未来缓解日期不进入当前上下文。

v2保留原2139条病例及eGFR/CABG值、原来源记录；仅新增年龄和记录态冠心病。训练／验证／测试CAD阳性124／32／36，年龄1433／355／351条可得。它表示源记录状态，不是独立临床确认当前病情。独立只读源审计复核了病例集合、旧字段保持与训练/验证数值一致。

每条新增规则明确为agent来源形式化，未冒称新一次BIBM模型提取。华法林旧错误例外规则仍禁用。未知患者事实、未知产品、已知但范围外产品分别处理；不以ATC类别反推成分，不读取当前真实药品答案。

## 固定评价设计

1. 复用原保存的351条推荐，其中344条支持、7条拒绝；候选593个、无序候选药对387。只重放核查，不再次运行或训练模型。
2. 旧规则＋旧事实、旧规则＋新事实、新规则＋旧事实、新规则＋新事实四个分支。规则包包含其身份快照，产品适用范围调整是其中一部分，不将耦合改变称单机制消融。
3. 旧规则旧事实须逐例复现原CheckReport；所有分支候选不得改变。病例分母、单药规则次数与药对次数分别报告；一条规则完成不等于整份处方完成。
4. 由独立角色先读官方原文、逐条编写并冻结[40条明确虚构参照](../resources/check-reference-v1.md)，不从新生产执行器或测试输出生成期待。含5个规则族：8条应标记、7条限定规则内不触发、16条unknown、9条不适用。
5. 参照采用四态混淆矩阵，单列unknown误判通过、漏标与误标；实际病例没有独立临床真值，不报告其clinical accuracy。参照角色共享基础模型及部分来源，角色/实现隔离不等于统计独立或专家金标准。

具体限制由固定预测与字段交集解释：

- 29次二甲双胍候选中，仅2次有有效同次eGFR，其余27次不能判断。全测试14条有eGFR，不代表都推荐该药。
- 55次布洛芬200mg、34次萘普生钠220mg候选都没有对应的明确同次CABG事实，89次规则保持未知；无手术记录不能改成false。
- 测试虽有36条记录态CAD阳性，模型本次没有哌甲酯候选；不为了触发警告把真实处方补进候选。
- 阿片产品出现4次、地西泮出现1次，未在同例构成所定义的组合。387个无序候选对均不在本次组合规则范围，不能改称387对安全或已全面核查DDI。
- 100mg布洛芬候选出现13次，范围证据不足而保留未覆盖，未借粗类别或其他剂型强行补齐。

独立编写参照的首次评分为**40/40一致**：8/8应标记、7/7限定规则内不触发、16/16未知、9/9不适用；unknown误判通过0、应标记漏报0、非标记误报0。这只覆盖冻结的40种来源语义情境，不是40名真实患者，不是临床准确率100%。期望标签始终未根据生产结果修改，冻结SHA256见聚合JSON。

### 范围计数的一次纠正

首次运行已保存在 `outputs/data_evaluation/check-coverage-20261114/`。当时仅为15个规则相关产品保存详细身份，其他已有NLM术语记录的药品被过度记为身份待补：出现455次身份缺失记录、223个药对pending，新分支外层状态为155未覆盖／188缺信息／1 checked，仍只有2次单规则执行。

这并非患者缺少了额外病史。最终产品审计版`rxnorm-rule-products-v2.1`补充已有77个官方原码的清单，仅据精确allowlist辨认已知范围外；不为它们捏造完整身份，也不新增医学允许范围。任意未知编码、范围内身份不足仍为unknown。修正后范围外计数正确，40条参照仍全部一致；临床条件、允许产品、候选及2次执行数没有变化。最终产物使用独立目录 `outputs/data_evaluation/check-coverage-v2-20261114/`，没有覆盖首次结果。不能将pending减少宣传为核查覆盖提高。
