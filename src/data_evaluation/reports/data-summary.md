# A1 v3 实际运行与交接报告

核验日期：2026-11-07。配置见 [preparation.json](../configs/preparation.json)，命令见 [模块 README](../README.md)。v3 允许空操作集合；模型原类的5种实际计算检查见 [空操作核验](empty-procedures.md)。原表只读，v1/v2 本地产物不覆盖。

## 数据规则

全量 visits.jsonl 保留全部可关联就诊。主任务候选要求诊断和药物有效、时间有效、每位患者至少两次有效就诊，不要求操作非空。操作缺记录时保留 [] 并标记 not_recorded，不填造操作编码，不推断临床上从未做过操作。

候选当前药物仅作为标签，推理输入中剥离。历史限于筛选后同患者已经结束且严格早于当前开始的就诊，药物另按记录起始时间裁剪。不补慢性病延续，过敏/肾功能保持未知。后续B已完成单独的映射与SSPNet运行，见 [B报告](../../recommendation/reports/sspnet-synthea-v3.md)；本报告的样本数为映射前A1口径，A2/A3仍待完成。

## 缺失与排除

Demo 7次就诊没有有效药物代码；其余122次中，81次属于不足两次有效就诊的患者，最终候选41次。原始129次均在全量文件。空/0药物代码共1478行，保留原始药物记录用于审计。

Synthea 的缺诊断45696次、缺药物26077次可重叠，合计50155次未进入有效候选；有效的3191次中243次因患者不足两次未入选，候选2948次。空操作不会再产生排除原因。原始53346次均在全量文件。

两套数据均满足原始就诊=记录条件未入选+患者条件未入选+候选就诊。Synthea 全量仍有1807次相同起始时间额外就诊、5189次区间重叠就诊；Demo两项均为零。它们不从全量层删除，历史时间单独限制。Demo仅供流程检查；Synthea为合成病历，不能代表真实临床效果。

## 验证与证据

- 11个标准库测试通过，新增空操作当前/历史保留、缺记录状态以及严格开关的回归检查。
- 模型隔离核验5个场景的 eval/train 模式前向反向均为有限值；完整包导入仍受 torch_geometric 缺失影响，不能称完整训练已通过。
- 两套数据在临时新目录重跑，全量、候选、预测文件及划分完全一致。
- 批量逐条核验患者集合不交叉、当前药物标签分离、历史严格早于当前、空操作状态一致和筛选计数守恒。
- patient 10059 两次住院仍为9/2/25、14/8/70；仍可形成第二次住院的有历史预测样本。

## B 的读取约定

本地目录为 data/processed/data_evaluation/mimiciii-demo-1.4-v3/ 与 synthea-apr2020-v3/。visits.jsonl 是全量层，visits.audit.jsonl 是其别名；main_visits.jsonl/split.json 是模型候选及其患者划分；main_prediction_examples.jsonl 是严格有历史样本，prediction_examples.jsonl 另保留没有可用历史的候选。

B 不得用 inner join 或补假操作重新丢掉空操作病例。原操作编码分支能处理空张量，但包依赖、训练接口、绘图、未初始化参数和原评估的三次过滤仍需适配。若整个训练集无任何操作编码，则需另核验零大小词表，本次非零词表检查不覆盖该情况。

这些是A1的组织结果，B的药物映射/词表适配可能进一步减少有效样本，需继续报告覆盖。其他成员按README从同版本公开源文件重建，病例、划分清单与权重不进入Git。共享协议仍为0.1-draft，等待三方复核后冻结。
