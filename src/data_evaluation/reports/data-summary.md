核验日期：2026-11-07。实现与命令见 [模块说明](../README.md)，配置为 [preparation.json](../configs/preparation.json)。源表未改动，病例级文件只存本地。

## 规则与边界

v2 分别归组诊断、操作、药物，按患者和真实起始时间排序；原始字符串编码保留前导零，同就诊内去重。visits.jsonl 保留全部可关联就诊，包括单次就诊、缺失记录和异常时间。main_visits.jsonl 单独保存三类编码非空、每人至少两次有效就诊的候选。原始缺失与空/0 药物代码单独计数，不将其视为正常药物。

不做成分归一化、ATC 映射、慢性病延续、药物关系图或模型训练。B 在固定患者归属上继续映射和筛选，不重新挑选测试患者。

## 缺失与时间审计

Demo 的无正常药物编码就诊 7 次、无操作 16 次，22 次不进入有效候选（原因可重叠）；另有 71 次有效就诊因患者不足两次而不进入主任务候选。无效空/0 药物代码共 1,478 行。所有这些就诊仍保留在全量文件。

Synthea 缺诊断 45,696 次、缺药物 26,077 次、缺操作 32,274 次；原因非互斥，不能直接相加。52,089 次不进入有效候选，再按患者条件排除 422 次。计数满足原始就诊=两阶段未入选+主任务候选；全量文件仍保留全部 53,346 次就诊。操作非空是尚未改变的首版兼容条件，不能称所有保留病例都已适配模型。

Synthea 全量排序审计发现 1,807 次相同起始时间的额外就诊、5,189 次与此前就诊区间重叠的就诊；Demo 两项均为零。模型候选不因此直接删除，但构造完整历史时仅取已结束且严格早于当前开始的就诊。预测示例中历史药物另按开药日期裁剪；未知日期不进入已知历史药物。没有历史时是 null，不假称已确认无历史。

## 交接给 B

本地目录为 data/processed/data_evaluation/mimiciii-demo-1.4-v2/ 与 synthea-apr2020-v2/。v1 不覆盖。每个目录有全量 visits.jsonl（visits.audit.jsonl 为兼容别名）、主任务 main_visits.jsonl、split.json、全部候选 prediction_examples.jsonl、有可用药物历史的 main_prediction_examples.jsonl、manifest.json、summary.json。

其他成员按 README 从同版公开源文件重建；不通过 Git 共享患者文件。B 读取 main_visits.jsonl 和 split.json 建立词表/图，使用 main_prediction_examples.jsonl 作为有历史主任务样本。全量文件中未入选的病例没有本次主任务集合归属，后续单次就诊对照需制定与现有患者归属兼容的划分。

公开 SSPNet 评估函数仍跳过少于三次就诊患者，B 必须显式适配其评估入口和就诊样本掩码，否则会漏评新增病例。主任务样本数是 A1 组织结果，后续药物映射/未知词表还可能缩小有效数，B 需继续汇报。manifest 记录代码提交与工作区状态，开发运行的 dirty=true 如实保留。
