# 当前研究问题与实验设计

2026-11-14。本文件记录研究设计；进度只更新三个模块的TASKS.md。用户明确纠正：主线是基于BIBM与SSPNet的模块实现及agent集成，零样本只作补充对照。暂不依赖申请中的数据；已有公开材料优先服务主线，不将新数据集或本地大模型安装变成前置条件。执行采用既有学术工作流：先证据与口径，再假设、预先确定的对照、结果审核，最后才写论文。已做诊断见[DDI报告](../src/recommendation/reports/ddi-audit-20261114.md)，新公开材料实测见[第一批实验](../src/knowledge/reports/open-data-pilot-20261114.md)。

## 1. 两篇论文怎样结合

SSPNet 提供结构化病例的候选药物；借鉴 BIBM 的文本知识提取、条件保留和规则化方法，产生有来源的核查规则；核查模块检查候选并显式报告缺信息或未覆盖。首轮只标记，不自动修改候选。一个最小agent负责检查病例字段、调用推荐与核查工具、记录补信息需求并输出来源；先实现明确流程，不增加多agent框架。

主线顺序：最小模块与共享接口 → agent调用链和集成检查 → 解决实际药物身份/条件缺口 → 固定病例上的模块对照。前两步已运行；来源核对参照与BIBM式自动提取规则在相同候选上分别执行，但当前成分级完整检查均为0条，不能由此声称核查有效。来源与逻辑由agent核对，未有同学或临床专家审核。原BIBM诊断单独验收；零样本及DialMed后移。知识抽取和独立零样本病例实验是不同工作；后端不绑定Qwen，无需新增CUDA。

原BIBM诊断另行验收：现有来源摘要经模型形式化、agent核对后保留12条规则，受限条件MLN实测47/104（45.19%），低于旧Diaformer的79/104。完整知识检索、原文迭代优化和Alchemy运行尚未恢复。DXY与Synthea/MIMIC无共同患者，不拼成虚假的端到端病例。用药规则是新增适配，不能叫原文已有功能。方法、输入边界及固定对照见[本轮报告](../src/data_evaluation/reports/agent-integration-20261114.md)。

候选研究问题是：**药物表示和患者条件不完整时，显式传递映射歧义与缺失条件，能否在相同明确判断覆盖率下，减少无依据报警和错误放行？**

覆盖率指作出明确判断的待核查单元比例，不是 CID 可连接比例。未触发规则只能表示“在所用规则与已知条件内未触发”；规则覆盖外仍未知。映射到 ATC 类别不能反推出确定的药物成分。只输出类别的模型须保留这一限制，另做真正预测成分的实验时统一全部比较方法的输出空间。

## 2. 已核查的近邻与剩余问题

本轮为定向近邻检索，不是穷尽系统综述。

| 近邻 | 已有工作及对我们的约束 | 阅读范围 |
|---|---|---|
| [SafeRx-Agent，2026预印本](https://arxiv.org/html/2605.29146v2) | 已有 ATC4 推荐、知识核查、多专家及粗类别风险高估讨论；Appendix E 将知识矩阵外关系按0计。不能把“更细编码＋医疗agent”直接当贡献 | 已读任务、核查、评价及相关附录 |
| [GiantMed，作者论文](https://www.cs.emory.edu/~jyang71/files/giantmed.pdf) | 深度推荐与 LLM 边界病例处理已有近邻；先预测再用LLM核查并非空白 | 摘要、首页与[作者代码](https://github.com/lvhangkenn/GiantMed)，未完整复核实验 |
| [MedAbstain，EACL2026](https://aclanthology.org/2026.eacl-long.291/) | 医疗问答缺失上下文与拒答已系统研究；增加未知状态本身不是创新 | 官方摘要、引言及代码 |
| [Navigating uncertainty matters，JMCP2026](https://pmc.ncbi.nlm.nih.gov/articles/PMC13505366/) | 已研究 DDI 识别拒答与错误风险；250份清单均含交互，不能评价无交互特异度 | 方法、数据与局限 |

只有在固定候选、相同知识来源和可比判断覆盖率下仍有收益，且不能被简单条件规则解释，才继续提出方法贡献。若确定性的“成立/不成立/未知”规则已同样有效，保留简单实现，不叠加多agent结构。

正式主队列预设至少两次有效就诊，保留空操作；历史必须结束于当前就诊前。完全无历史患者单立任务，不以测试分数高低决定是否纳入。回顾性诊断/操作记录不能冒充入院时已知条件。

在本轮核查范围内，尚未找到无需审核且足够大、真实、可排序多次住院并含完整药物目标的直接替代品。MIMIC-IV本人申请见 [具体步骤](mimic-access.md)。eICU 同年不同住院缺系统排序，HiRID 不能跨次入院关联，均不直接接入当前纵向主任务：[eICU字段](https://github.com/MIT-LCP/eicu.mit.edu/blob/main/_eicutables/patient.md)、[HiRID说明](https://physionet.org/content/hirid/1.1.1/)。

## 4. 按依赖推进的实验

| 实验 | 固定什么／只比较什么 | 交付与停止条件 |
|---|---|---|
| E0 口径诊断 | 固定38类与已存预测，重建源图；全事件图只作敏感性分析 | 可追到CID和事件；区分类别边、成分证据和未知。不得选择DDI较低的图 |
| E1 廉价推荐对照 | 固定划分；历史用药、训练频次、现有SSPNet；空操作和历史数分层 | 描述性表，不对既有测试调参；当前已执行，见DDI报告 |
| E1b 损失探针 | 固定检查点与32条训练样本，无参数更新；检查梯度、分母、beta | 确认公式及影响范围；不能倒推整个历史训练过程 |
| E2 条件核查最小实验 | 已用3条有出处规则检查成立/不成立/缺失及例外；自动提取2条采纳、1条拒绝 | 来源核对参照与自动规则分开；边界样例只算工程检查，尚无独立临床标签 |
| E3 零样本核查与推荐 | 下节预设的少量对照，共享病例、药物空间与知识来源 | 先小批验证输出有效性与成本，再决定扩展；没有实际推理不填结果 |
| E4 正式确认 | 新真实患者/独立来源、冻结规则及阈值；学习方法同一组3个种子 | 按患者聚类重采样估计差值区间；规则族配对输入按规则族成组，不能把就诊/改写当独立人 |

E2先用来源核对参照确定任务，随后测BIBM式自动提取；来源核对由agent执行，不能写成人类审核。原始失败、格式修订与输入域检查更正均保留，未按病例测试成绩补临床条件。独立评价标签不能直接复制参与训练/核查的同一DDI图。250例用于定位和拒答后错误，不据其全阳性结构估计特异度。

只有在分母问题确实影响研究问题时，才增加固定38类同条件的损失分母对照；不同时改图、词表、队列和超参数。当前不启动200轮或大规模参数搜索。

## 5. 零样本方案（补充对照，主线之后）

本项目“零样本”指不使用本任务标注病例训练大模型，也不在提示词提供已解答病例示例；仍允许当前病例和其真实历史作为输入。公开文献/规则检索版本单列为 retrieval-augmented zero-shot。不把“无历史患者”“SSPNet在本任务训练后预测新患者”或提示词示例学习混称零样本。

SSPNet加零样本核查是混合系统，只有核查模块是零样本；不能称整个系统零样本。以下候选留待主线跑通后按必要性选择，不默认全部执行；补充实验内优先核查，直接推荐可选：

1. **Z0：固定候选、无检索的大模型核查**。只给允许的病例事实、候选及编码解释；记录输出格式失败、无根据来源和不确定状态。
2. **Z1：同一大模型＋固定检索证据核查**。与确定性规则基线使用同一份来源，不加入已解答案例。提示词、检索策略先在开发材料固定；不检索测试集标注或含答案的基准论文。
3. **Z2：大模型直接推荐**。提供与SSPNet相同的可用病例事实和药物候选字典，不提供当前用药答案。分别记录有/无检索，推荐标签空间必须一致；不能让某方法得到额外诊断或真实成分。没有全词表可比分数时不伪造AP，只报告集合指标、输出覆盖与未知编码。
4. **Z3：待验证的缺失感知核查**。对照Z1和简单三值规则；保持候选不变，比较同等覆盖率下错误，另报全部拒答的零覆盖参照。不得只删除药物来降低DDI。

固定模型仓库/修订号、量化版本、推理设置、token限制、上下文/截断和提示词版本；不直接将模型自报置信度当已校准概率。覆盖率比较阈值/策略只在开发集确定，最终测试报告实际覆盖及误差曲线；不在测试标签上挑最优点。记录检索次数、延迟和token，防止用更多资源冒充方法收益。

已实现本地推理调用和两种任务的独立评价入口，冻结清单与文本pilot；[本地Qwen环境](../src/knowledge/LOCAL_INFERENCE.md)已用CPU完成主线知识形式化，服务已停止，尚无零样本病例实验结果。不默认购入API或把受控病例发到外部服务。若提示词或阈值用标注开发病例优化，应称“无微调、经开发集选择”，不能宣称严格零任务监督。输入位置捷径及七分类范围修订记录在协议10.1，不能抹去这些探索性调整。

## 6. 最终报告必须回答

- 新方法是否超过简单规则及同来源零样本核查？收益能否在同等判断覆盖率、相同药物数和固定病例下维持？
- 映射、抽取、缺信息与推理错误各占多少？只读类别的输出如何处理不可判定成分？
- 是否在真实未参与开发的患者上保持方向？外验的数据来源与人群是否真正独立？
- 失败、格式错误、未知和拒答是否都计入分母？是否同时报告药物预测质量、图标记率和人工参考核查质量？
- 如果结果不支持假设，能否以较简单系统解释现象并停止加模块？
